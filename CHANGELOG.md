# Changelog

Один номер версии везде:

| Где | Как называется версия |
|---|---|
| Этот файл | раздел `## vX.Y — ДД.ММ.ГГГГ` — главный источник |
| Git / GitHub | тег `vX.Y` + Release с этим же текстом — **создаются автоматически** после мержа |
| Figma | вкладка `🗂 vX.Y · дата` — замороженная копия всех 4 макетов + список изменений |

**Правило:** новая версия = смерженный pull request, в котором поменялось что-то видимое на сайте.
`X` растёт при смене направления дизайна, `Y` — при каждом обновлении.

**Как выпускается версия (вручную ничего называть не нужно):**
1. В PR раздел `## vX.Y — в работе` получает дату вместо «в работе».
2. Claude в том же заходе делает вкладку `🗂 vX.Y` в Figma.
3. Никита мержит → GitHub Action сам ставит тег и публикует Release (страница Releases = блог изменений).

**Откатиться:** в Git `git checkout vX.Y`, в Figma открыть вкладку `🗂 vX.Y`.
