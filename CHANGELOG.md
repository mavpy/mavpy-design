# Changelog

Один номер версии везде:

| Где | Как называется версия |
|---|---|
| Git | тег `vX.Y` (+ GitHub Release с описанием) |
| Figma | именованная версия `vX.Y — …` в истории файла (File → Show version history) |
| Этот файл | раздел `## vX.Y` |

**Правило:** новая версия = смерженный pull request, в котором поменялось что-то видимое на сайте.
`X` растёт при смене направления дизайна, `Y` — при каждом обновлении.

**Откатиться:** в Git `git checkout vX.Y`, в Figma «Restore this version» у версии с тем же номером.
